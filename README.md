📌 Projekt‑Name
iki1uc · NEWADA System  
Ein modularer Mehrraum‑Operator, bestehend aus fünf Haupt‑Räumen, die zusammen ein vollständiges, dynamisches NC‑System bilden.

📌 Ein‑Satz‑Beschreibung
Ein mehrschichtiges, selbsttragendes System, das ENGINE‑Logik, INDUSTRY‑Produktion, MARKT‑Austausch, SPRUNG‑Bewegung und VECTOR‑Richtung in einem einzigen Repository vereint.

📌 Warum dieses Projekt existiert
Dieses Repository bildet die Grundstruktur des iki1uc‑Systems, inklusive:

Raum‑Logik

Operatoren

Ready‑Flags

Panels

APIs

Live‑Status

Index‑Konsolen

Es ist die Basis, auf der deine NC‑Attack‑Super‑Show‑index.html läuft.

📌 Ordner‑Struktur (Chef‑klar, NC‑rein)
1. ENGINE/
Der Kernraum.
Beinhaltet Operatoren, Räume (T, X, Z), CORE‑Achsen und die zentrale Engine‑Konsole.

2. INDUSTRY/
Produktionsraum.
PQ‑Module (3.js, 81.js, 243.js), RIR.Core, XyX.js, KIT.js, Dokumente und die Industry‑Konsole.

3. MARKT/
Austauschraum.
API.raw, API.system.js, Markt‑Operatoren (1.js–4.js), genie.js, push.js, time.js, x/y/yx.js.

4. SPRUNG/
Bewegungsraum.
move.js, Panels, hi.ready, Sprung‑Konsole.

5. VECTOR/
Richtungsraum.
API‑Module, genie.js, push.js, stand.js, time.js, Vector‑Konsole.

6. Live.tmp
Live‑Status‑Datei.
Zeigt an: System ist aktiv.

7. index.html
Die Haupt‑Konsole des gesamten Systems.

📌 Features
5 Räume vollständig integriert

Alle Module verlinkt und nutzbar

NC‑Attack‑Modus (alle Systeme gleichzeitig)

Schauer‑Modus (automatischer Durchlauf)

Super‑Show (3D‑Cube, Neon, Score, Log)

Filter‑System (Raum‑Ansicht)

Live‑Log (farbig, zeitgestempelt)

Score‑System (algorithmisch)

iki1uc‑rein (keine Fremdanteile)

📌 Quick‑Start
Repository öffnen

index.html starten

Navigation nutzen (ENGINE, INDUSTRY, MARKT, SPRUNG, VECTOR)

NC‑ATTACK drücken → alle Systeme aktiv

SCHAUER drücken → automatischer Durchlauf

Log & Score beobachten

📌 Nutzung
Jeder Raum hat eine eigene Konsole (index.html im jeweiligen Ordner).

Jede Datei ist direkt anklickbar.

Live.tmp zeigt System‑Status.

Haupt‑index.html ist die General‑Konsole.
